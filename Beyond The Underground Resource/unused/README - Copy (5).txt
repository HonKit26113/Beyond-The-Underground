Changelog
Version 1.5.3
Released June 20, 2024

New Cave Type: 


New Blocks:


Changes:
 - ***This add-on no longer requires any experimental toggles to function!***
 - Slabs now work more similarly to those in vanilla. The top or bottom half of the block you place the slab on will determine its orientation.
 - Water droplet particles now appear under Dripping Icicles.
 - Crooked Trapdoors can now be placed on the bottom part of a block. 
 - Crooked Doors can no longer be used as fuel.
 - Merged the 4 Crooked Door IDs into one. Note that all Crooked Doors that were previously placed will disappear. 
 - Crooked Fences and Soul Brick Fences now link with other blocks.
 - Player movement is now slowed down when consuming food from this add-on.
 - The "Locked Lava Tanks cannot be emptied" message no longer appears when placing Locked Lava Tanks.
 - Stepping on Slimy Blossoms no longer gives the Poison effect.
 - Removed the Sand Layer and Slime Layer items and added their block counterparts to the creative menu and crafting recipes.
 - Suitcases no longer catch fire.
 - This add-on now requires Minecraft 1.21.20 or above to function.

Fixed Bugs:
 - Fixed an issue causing Lava Tanks to not function in versions newer than 1.20.60.
 - Dripping Icicles now drop the correct item when broken.
 - Double Crooked Slabs now drop when broken.
 - Crooked Doors no longer catch fire and burn.
 - Frosted Deepslate and Soul Magma Blocks now drop only when broken using a pickaxe.
 - Blocks in the add-on now have a chance to drop after an explosion.
 - Fixed an issue causing some blocks not to appear in the command auto-fill.
 - The Soul Healer item is now removed upon use.
 - Sound errors no longer appear in the content log.
